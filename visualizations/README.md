# Visualizations

Charts created by dashboard.py (and dashboard.ipynb) from sales_data.csv.

## Seaborn charts (pictures)
1. 1_boxplot_product.png : box plot of order values for each product
2. 2_violin_region.png : violin plot of order values for each region
3. 3_correlation_heatmap.png : heatmap of the correlation between Quantity, Price, Total_Sales and Month
4. 4_dashboard_grid.png : 2x2 dashboard with a bar chart, line chart, scatter plot and histogram

## Plotly charts (interactive, open the .html file in a browser)
5. 5_interactive_bar_dropdown.html : bar chart with hover details and a dropdown to change the measure
6. 6_interactive_line_dropdown.html : monthly sales line chart with a region dropdown
7. 7_animated_sales_by_month.html : animated bar chart, press Play to see each month
8. 8_interactive_dashboard.html : full 4-panel interactive dashboard
